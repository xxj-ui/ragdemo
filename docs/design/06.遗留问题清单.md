## 5. M1 交付与实测（2026-11-02）

**新增/改写代码**

| 文件 | 内容 |
| --- | --- |
| `server/document_repository.py` | 7 个方法写 SQL（`list_all` / `get` / `find_by_filename` / `insert` / `replace_meta` / `update_chunk_count` / `delete`），全部支持复用外部事务连接 |
| `server/rag/chunk_repository.py` | 新增 `insert_for_document` / `delete_by_document`；删除 `init_table`（不再自建表） |
| `server/service/document_service.py` | 上传 5 步流水线 + 列表 + 删除；`DB_ERRORS` 统一映射 503 |
| `server/service/health_service.py` | 三项探测（DB `SELECT 1` / 模型状态位 / `DEEPSEEK_API_KEY`） |
| `server/storage.py` | 流式落盘 + 超限中断 + 转正 + 静默删除 |
| `server/deps.py` | 容器接线：仓储注入 DSN、`ConnectionPool(kwargs={"row_factory": dict_row})`、BM25 失效入口 |
| `server/timeutil.py` | 库内 UTC → 接口 `+08:00` |
| `server/rag/cli.py` | `--build` 改走同一写入路径，按文件逐个入库 |
| `server/routes/documents.py` | 修正响应组装：service 返回单项 → 包成 `items[]` |

**实测（PG 17.10 / Python 3.13.9 / CPU）**

- 上传 PDF 22.5 s（含模型冷启动 20 s±），热态覆盖 388 ms；列表 7.7 ms；删除 10.2 ms
- 数据层一致性 4 条 SQL 全 0 行；`embedding` 维度唯一 512；`source` = 原文件名
- 落盘顺序验证：覆盖时新文件就位、旧文件提交后才删；失败路径事务回滚且不留文件
- 数据库不可达 → `/documents` 503 `DB_UNAVAILABLE`、`/health` 仍 200 `degraded`

**未做（M2 范围）**：`/api/chat`（SSE）、三个历史接口、BM25 懒重建、检索链路。
